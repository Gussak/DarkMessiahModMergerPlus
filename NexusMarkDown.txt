[size=4][b]Installation instructions[/b][/size]

[size=3][color=#D4D4D8]Initially designed to be run on Linux using OverlayFS (one folder for each mod).[/color][/size]

[size=3][color=#D4D4D8]May work on cygwin under Windows (not tested), to be able to execute bash scripts and the patch command line.[/color][/size]

[size=4][b]Requirements[/b][/size]

[color=#d4d4d8]If you are on windows and want to try the mod merging bash scripts (.sh), look at [/color][url=https://www.nexusmods.com/7daystodie/mods/14]"[b]Installing (at Windows, on a cygwin terminal):[/b]"[/url][color=#d4d4d8].[/color]

On linux you will want to have OverlayFS installed, also 'jq' for JSON, pip install vpk (some of these things may be available for windows too I guess), may be other things.. the scripts will ask for them.

All content here are or original files (therefore there is no patching required, they work by just placing the files there).
Or patches, so the whole point is, I am not uploading final files that you can just overwrite and run, if they are patches it means it has just changes based on the vanilla files and need to be applied thru command lines keyValuePatcher.py and patch.

If you don't like to use command lines and patching tools and really want to use some mini mod, you can just apply the patch by hand. Just open the text file, look for each key and paste the value. The .patch files are not difficult to use by hand but you need to understand how they work (the + and -).
